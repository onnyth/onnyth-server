# Inbox

Drop a filled `backend-brief.md` here, then run `/sprint-workflow`.

The AI will:
1. Read `backend-brief.md` from this folder
2. Auto-detect the next sprint number
3. Create `sprints/sprint-{N}--{name}/` with plan + stories
4. Execute all stories (plan → build → test → update skills)
5. Delete `backend-brief.md` from this folder when the sprint is complete

Then you can drop the next brief and repeat.
